# Agape v1.0.2 — changelog

> The authoritative description of what v1.0.2 adds over v1.0.1 — the library and gate pieces the v1.0 language left unfinished. It is the merge artifact
> and the basis for the SPEC.md edits. **Backward compatible:** every well-typed v1.0.1 program is
> a well-typed v1.0.2 program with identical observable behavior (`obs`, §15.5.1). All additions
> are static/compile-time and **desugar to the frozen v1.0.1 engine** ("every sugar desugars",
> §14). Two parts: the **library layer** (A) and the **readable gate** (B), plus the formal
> grounding (C) that backs the gate.

---

## A. The library layer (SPEC §19)

A static packaging layer so agape code can be modularized, hidden, parameterized, and abstracted.

- **A1 — Modules & imports.** A module = one `.ag` file with an explicit `module path;` header
  (else the implicit root module). `import m;`, `import m as x;`, `import { a, b } from m;`.
  Resolution is a static link phase; cycles / unresolved / unexported imports = `ModuleError`.
  A **package** is a directory with `[package]` in `agape.toml` (`lib = "src/lib.ag"`); deps via
  `[dependencies]` (path / git, no registry yet).
- **A2 — Re-export.** `pub import { a } from m;` republishes `a` as part of the importing module's
  public surface, so a library's entry module can present a single-import facade
  (`import geometry;` gives the user everything).
- **A3 — Namespacing.** Fully-qualified names (`modpath.Ident`); the spine's event `etype` is now
  fully-qualified, so the same simple name in two modules is two distinct spine types. Built-in
  `Error`-subtype matching stays cross-module.
- **A4 — Visibility.** `pub`; default = module-private. Governs **names, not the spine** (a private
  event still lands on the spine for audit; outsiders just can't name it). `pub` is **shallow** (a
  `pub` signature may not expose a private type). Violations = `VisibilityError`.
- **A5 — Generics.** `struct` and `fn` carry plain type parameters (`struct Box<T>`,
  `struct Pair<A,B>`, `fn id<T>`), monomorphized at compile time. Agents and interfaces are not
  generic.
- **A6 — Interfaces.** `interface I { when EVENT decide RESULT; requires CAP }`. A type, not
  instantiable (`spawn` of one = `TypeError`). **Nominal**
  conformance: `agent A : I` must have a matching `when` handler per `when…decide` and the
  `requires` capabilities; failure = `InterfaceError`. An implementor is a subtype of the
  interface (`reach I` authorizes any implementor); interfaces erase at runtime.
- **A7 — Error subtyping.** `event Foo(..) : Error;` — single-level under the built-in `Error`
  root only (so `when (Error e)` catches it). Non-`Error` supertype = `TypeError`; `action`
  supertype = `ParseError`.

New conformance error classes: `ModuleError`, `VisibilityError`, `InterfaceError`.

## B. The readable gate — `decide` / `reversible` / `conformal`

A surface where a non-programmer states *intent + one fact about stakes*, and the decision theory
is **derived and enforced**. Desugars to the v1.0.1 engine (`endorse`/`attest`/`c by R`, §13).

- **B1 — One stakes keyword on the sink.** `reversible` annotates any **consequential sink** (an
  `action` or a `write tool`); unmarked = cautious/fail-closed. There is no other stakes knob.
- **B2 — Gate strictness = the strictest arm.** All arms reversible → **argmax-forever** (no
  labels, no principal, no conformal). Any non-reversible arm → **consequential** (warms over
  time).
- **B3 — Cold → warm phasing** (consequential gates):
  - *Cold* (labels < readiness): **argmax**. Reversible outcome → commit; non-reversible → **defer**
    to the principal. Deferrals become the labels.
  - *Warm* (labels ≥ readiness): run **conformal every time**. Per-outcome reversibility then
    *waives* (reversible → commit argmax) or *requires* (non-reversible → singleton-or-defer) the
    coverage guarantee.
- **B4 — One dial: `conformal α`.** The only number. An error guarantee (≤ α), calibrated from the
  spine. First-class at three scopes: file (`conformal 0.05;`), per-gate (`decide c conformal
  0.01 { … }`), and manifest default. Missing → defaults (0.05).
- **B5 — commit / default / defer (+ notify orthogonal).** Arms = commit; a `default:` arm = the
  autonomous safe fallback; a **principal** (the `alice decide` subject, or `defer to alice`) =
  the human who decides the contested/cold case (blocking). **notify = a plain `emit`** (no new
  construct).
- **B6 — Deference compile rule.** A `decide` with a non-reversible arm and **no reachable
  principal** is a **compile error** (autonomy is earned via human-label deferral; a `default:`
  does not substitute). An all-reversible `decide` needs no principal (declaring one = unused
  warning).
- **B7 — Distribution-source check.** A consequential (conformal) gate needs a distribution
  (provider logprobs, or the §16 sampling fallback). Neither available → **warning**: conformal
  degrades to pure deferral. The sampling fallback is manifest-switchable
  (`[provider] sampling_fallback = false`) for cost control.
- **B8 — Tie / no-plurality.** The programmer's `default:` arm is the tiebreak. Absent a
  `default:`, the gate **abstains** (no effect) and logs an `Abstained` event — never a silent pick.
- **B9 — Calibration scope = a programmer design decision (per-gate-site).** A gate calibrates
  from its *own* recorded decisions; scope is controlled by how gates are factored (no pooling
  construct). The language documents the pattern so authors build gates that accumulate a clean,
  exchangeable conformal dataset over time.
- **B10 — `Decision` introspection ("typeof" = provenance).** A `Decision<E>` exposes read-only
  `.committed` (variant / abstained), `.basis` (`Argmax | Conformal | Principal`), `.margin`. No
  general structural reflection (deferred — tensions with erasure/determinism).
- **B11 — No keywords beyond `reversible`, `decide`, `conformal`, `defer`.** No
  `irreversible`/`consequential` keyword (unmarked = cautious). The explicit v1.0.1 forms
  (`endorse (c by confidence θ margin δ)`, `conformal α`, `attest`, named `policy`) are **retained**
  for hand-calibration.

**Desugaring (engine unchanged):**
```
reversible action/tool X          →  arm admitted by  c by confidence 0   // argmax; relaxes margin floor m→0
unmarked action/tool X            →  arm admitted by  c by conformal α    // + readiness bootstrap
alice decide c { A: … default: … } →  endorse (c by <derived>) { A: … } abstain { default } by alice { … };
```

## C. Formal grounding (SPEC §15.5.6)

Establishes the gate's two guarantees as the evidence behind it:
- **Conformal coverage (α).** Nonconformity `s(x,y)=1−p̂(y)`; quantile `q̂` = the
  `⌈(n+1)(1−α)⌉`-th score over the spine's labeled decisions; set `C_α(x)={y:p̂(y)≥1−q̂}`;
  **`Pr(y_true ∈ C_α) ≥ 1−α`** (finite-sample, distribution-free, exchangeability-dependent — see
  B9). `α` = *correctness*.
- **The margin `g = p̂_top − p̂_2nd`.** `δ` (threshold-rule decision margin) and `m` (consequential
  sink floor) are the **same quantity `g`**, checked at two sites. `g` = *stability* (flip
  resistance, `β(g)→0`). `α` and `g` are orthogonal properties; `α` is **not** a margin.

## D. Conformance & migration

- **Conformance suite:** library-layer + gate sections added (`18_modules`, `19_visibility`,
  `20_generics`, `21_interfaces`, `22_gate`, + `09_prelude` error-subtyping); generic-agent/kind-bound
  tests removed; interfaces use `when…decide`. Multi-file tests via a `<id>.d/` companion dir + a
  `modules:` header directive.
- **Migration note:** the qualified `etype` (A3) changes **chain-head hashes** for the same source
  vs v1.0.1 (a representational change, not a semantic one; `obs` and all soundness preserved).
  Recorded v1.0.1 journals must be re-recorded under v1.0.2. `reversible` also relaxes the
  consequential margin floor `m`→0 for that sink.

## E. Deferred (not in v1.0.2)

Package registry / network fetch; arbitrary user subtype hierarchies (only single-level under
`Error`); general structural `typeof`/reflection; a cross-site calibration-pool construct;
separate compilation (monomorphization is whole-program).
